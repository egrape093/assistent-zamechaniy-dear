# Ассистент замечаний ДЭАР

Записка для Claude о том, как устроен этот проект и каких правил держаться.

## Что это
Веб-страница, которая превращает свободный текст замечания в формализованную
формулировку по регламенту ДЭАР. Работает напрямую с ИИ Claude (модель Opus 4.8)
прямо из браузера, без сервера и без сборки.

## Главные правила
- **`ключ.txt` — секрет. НИКОГДА не коммитить и не показывать его содержимое.**
  В нём личный API-ключ Anthropic (`sk-ant-...`). Он уже в `.gitignore` — так и
  должно остаться. Перед каждым коммитом проверяй, что в него не попал ключ.
- **Весь код — в одном файле `index.html`** (HTML + CSS + JavaScript вместе).
  Никакой сборки, фреймворков и зависимостей. Не разбивать на части без просьбы.
- API-ключ пользователя хранится только в браузере (`localStorage`) и больше
  никуда не передаётся. Не менять это поведение.

## Стиль
- Тёмная тема в духе бренда Sminex: тёмный фон, бежевые акценты.
- Шрифт — Futura (с запасными вариантами).
- Язык интерфейса, комментариев и сообщений коммитов — **русский**.

## Как менять и проверять
- Менять страницу — аккуратно: это рабочий инструмент, ломать его нельзя.
  После правок `index.html` стоит открыть файл в браузере и убедиться, что всё
  работает.
- Изменения оформляем через ветку → коммит → PR (так же, как делали раньше).
