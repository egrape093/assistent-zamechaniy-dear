# Ассистент замечаний ДЭАР

Веб-страница, которая превращает свободный текст замечания в формализованную
формулировку по регламенту ДЭАР. Работает напрямую с ИИ Claude (Opus 4.8)
прямо из браузера.

## Как пользоваться

1. Открой `index.html` в браузере.
2. Вставь свой Anthropic API-ключ (он сохраняется только в твоём браузере,
   в `localStorage`, и никуда не передаётся).
3. Введи текст замечания и получи формализованный вариант.

> Нужен интернет: страница обращается к API Claude напрямую из браузера.

## Безопасность

API-ключ нигде не публикуется. Файл `ключ.txt` добавлен в `.gitignore`
и **не попадает** в репозиторий.

## Стек

Один файл `index.html` — HTML, CSS и JavaScript без сборки и зависимостей.
